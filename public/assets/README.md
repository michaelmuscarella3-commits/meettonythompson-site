# Media files

Copy the site's images, videos and PDF here from the live server
(`public_html/assets` → `public/assets`, `public_html/videos` → `public/videos`).
File names must stay exactly as listed; the code refers to them by these paths.

Also copy the favicons and root files from `public_html` into `public/`:
`favicon.ico`, `favicon.svg`, `favicon-*.png`, `manifest.json`, `robots.txt`,
`hero-bg.png`, `logo.svg`, and `assets/logoFull.png` / `assets/images/meetTony.jpg`
(used by the social-share tags in `index.html`).
